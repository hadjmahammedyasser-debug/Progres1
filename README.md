# تذكير حجز الوجبات — PWA (مجلد واحد)

الملفات: `index.html` · `manifest.json` · `sw.js` · `icon.svg`

## النشر على GitHub Pages
1. ارفع الملفات الأربعة إلى جذر مستودع (فك الزيب أولا).
2. Settings ← Pages ← Deploy from a branch ← `main` / `(root)`.
3. افتح الرابط من Chrome على أندرويد ← ⋮ ← **تثبيت التطبيق**.

## ملاحظات
- لا يوجد API رسمي للحجز: التطبيق يذكّر ويفتح بوابة WebEtu، ويؤكد الطالب الحجز يدويا.
- لا يُخزَّن أي بيان دخول؛ البيانات في `localStorage` على جهازك فقط.
- التذكير الموثوق في الخلفية: زر "تذكير يومي للتقويم (.ics)".
- لاحقا: Supabase (مزامنة) وWeb Push (إشعارات الخادم) يُضافان فوق هذا النموذج.
